# Traceability: objectives and requirements → code → tests → evidence

**Sources:**
- Objectives and research questions are quoted from the project proposal (Research Objectives, Research Questions).
- Requirements are taken from [ARCHITECTURE.md](ARCHITECTURE.md) §1–§11.

**Conventions:**
- Code paths are relative to the repository root.
- Backend tests live in `backend/tests/`; frontend tests in `frontend/src/` (vitest) and `frontend/e2e/` (Playwright).
- Evidence is an evaluation result, a measurement recorded in [PROGRESS.md](PROGRESS.md), or a manual check.
- **Pending** marks evidence that needs human input listed in [HUMAN_TODO.md](HUMAN_TODO.md).

## 3. Engineering rules (CLAUDE.md)

| Rule | Code | Tests | Evidence |
|---|---|---|---|
| Heavy dependencies behind interfaces with fakes; tests need no models or Ollama | `interfaces.py`, `backend/tests/fakes.py` | `test_fakes.py`, `test_socket_guard.py` | `./scripts/check.sh` runs with sockets disabled |
| Never fabricate statute text, sources or contacts | `config/referral_resources.json` (empty, verified-only), `docs/HUMAN_TODO.md` | `test_frontend_contract.py::test_referral_resources_hold_only_verified_named_entries`, `test_glossary.py::test_shipped_glossary_is_flagged_and_large_enough` | — |
| Privacy: no question/answer/chunk text in logs or feedback | `logging_setup.py`, `feedback.py`, `main.py` | `test_logging.py::test_content_fields_redacted_by_default`, `test_api.py::test_no_content_in_logs`, `test_hardening.py` (error and fuzz paths) | — |
| Untrusted input: length cap, control chars, prompt markers | `security.py`, `models.py`, `web.py` (body limit) | `test_security.py`, `test_hardening.py::test_fuzzed_questions_never_break_the_api_or_the_prompt`, `test_hardening.py::test_hostile_bodies_get_a_4xx_error_body`, `test_hardening.py::test_static_route_never_serves_files_outside_the_build` | `pip-audit` and `npm audit` clean (LICENSES.md) |

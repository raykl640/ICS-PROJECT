# When a session goes wrong
Stuck loop / tests keep failing: stop. Run `git diff --stat`, then say in 5 lines what you tried and what the failing assertion actually shows.
Propose two different approaches, pick one, and try it once. If it fails, revert to the last commit (`git checkout .`) and report.
Context bloated: `/compact keep: current milestone, failing test names, decisions made`, or commit, update PROGRESS.md and /clear.
